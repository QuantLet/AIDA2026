# AIDA_aug_local_llm

The same experiment with open weights, so it can be reproduced without a commercial key. Imports the prompt and parser from the commercial stage, so the two legs differ in exactly one thing: which model reads the prompt.

- **Datafile:** data/lab/returns_*.csv
- **Output:** precomputed/local_*.csv
- **Part of:** AIDA Summer School 2026 - AI in Financial Risk Modelling (August course)

Reproduce with `../../run_all.sh` from the package root; this folder is the extracted, citable form of one stage.
